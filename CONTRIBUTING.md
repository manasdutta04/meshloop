# Contributing to Meshloop ARCA

First off, thank you for considering contributing to Meshloop ARCA! It's people like you that make Meshloop such a great tool.

## How to Contribute

### Reporting Bugs

If you find a bug, please create a new issue on GitHub.
*   **Describe the bug:** A clear and concise description of what the bug is.
*   **Steps to reproduce:** Please provide specific steps to reproduce the behavior.
*   **Expected behavior:** A clear and concise description of what you expected to happen.
*   **Screenshots:** If applicable, add screenshots to help explain your problem.
*   **Environment:** What OS, browser, or environment were you using?

### Suggesting Enhancements

If you have an idea for an enhancement, please create a new issue.
*   **Describe the enhancement:** A clear and concise description of the suggested enhancement.
*   **Why is this useful?** Explain how this would benefit the project.

### Submitting Pull Requests

1.  **Fork the repository** and create your branch from `main`.
2.  **Ensure you have set up the environment** as described in the `README.md`.
3.  **Make your changes**. Ensure your code adheres to the existing style.
4.  **Test your changes**. Ensure `test_connection.py` and other checks pass.
5.  **Create a Pull Request**.
    *   Title the PR appropriately.
    *   Describe the changes you made in detail.
    *   Link any relevant issues.

## Development Setup

See the `README.md` for full instructions on setting up the backend (FastAPI, Semantic Kernel) and frontend (Next.js).

## Code Style

*   **Python:** Follow PEP 8 guidelines. Use type hints for all functions.
*   **Frontend:** Follow standard React/Next.js conventions. Write CSS in `globals.css` and follow the project's styling.
